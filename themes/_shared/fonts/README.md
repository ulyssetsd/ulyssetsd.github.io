# Bundled fonts

Inter and Source Serif 4 are distributed under the SIL Open Font License 1.1.
The original copyright notices and full licenses are included alongside the fonts:

- `inter-OFL.txt`: https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
- `sourceserif4-OFL.txt`: https://github.com/google/fonts/blob/main/ofl/sourceserif4/OFL.txt

These are the original Latin WOFF2 files served by Google Fonts, without local
modification. `sources.json` records their download URLs. The shared renderer embeds
the font files and full license notices in every generated HTML document.

The build uses the checked-in files and does not contact a font provider.
